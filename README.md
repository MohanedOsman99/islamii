islamic app (quran suras _ahadis)

Overview

The Islami App is a modern digital platform designed to make exploring the Quran and Hadiths simple, 
interactive, and visually engaging. It combines traditional Islamic content with a clean, user-friendly interface.
---
Features

* Splash Screen
A welcoming screen that introduces the app’s identity and sets the tone for the user experience.
* Main Screen
Displays all available Surah images in one place. Users can scroll through and explore easily.
* Search Functionality
A powerful search bar allows users to quickly find any Surah or Hadith by typing its name.
* Hadith Section
Dedicated tab for Hadiths. Users can browse, read, and navigate between Hadiths seamlessly.
* Smooth Navigation
Tap between Surahs and Hadiths effortlessly, ensuring a fluid and intuitive experience
